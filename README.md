# test_tasks

## start && install

```
# firstly you should insert your bot private key in dev/.dev.env file
npm ci && npm run dev start
```


## Notes
Это bare minimal бот для игры в уно в тг для двоих.
Вы не найдете тут продуманной архитектуры а тестировка будет достаточно усложнена
по причине остутсивия выделенный архитектурных слоев.
Но все же некоторые моменты которые я учитывал:
* реализация в классе - как минимум нету глобального состояния и в целом можно тестировать если замокать ctx телеграфа
* бизнес логика разделена на отдельные функции, хотя некоторые edge кейсы явно требуют доработки, например обратка кейса когда игрок взял карту и может её тут же сыграть реализовано как чистейший костыль
* обработка ошибок должна было бы быть сильно продуманнее и лучше, есть кейсы когда явно стоит завершить игру и в большинстве случаев можно попытаться сообщить игрокам об ошибке
